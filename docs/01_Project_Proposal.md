# MarketMind AI

## Vision

MarketMind AI is a full-stack AI-powered investment research platform designed to help investors analyze stocks, IPOs, ETFs, cryptocurrencies, and portfolios across US and Indian markets.

## Objectives

- Portfolio Management
- IPO Analysis
- AI News Summarization
- Technical Analysis
- Fundamental Analysis
- Personalized Investment Recommendations
- Multi-Agent AI Architecture

## Technology Stack

Backend:
- Python
- FastAPI

Frontend:
- React
- Next.js

Database:
- PostgreSQL

AI:
- GPT-5.5
- LangGraph

Deployment:
- Docker
- AWS
