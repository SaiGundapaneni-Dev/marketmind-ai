# IPO Data Strategy

## Goal

MarketMind AI should analyze IPOs using verified, traceable data sources instead of mock data.

## Data Needed

- Company name
- IPO status: upcoming, filed, priced, listed, withdrawn
- Exchange
- Ticker
- Expected IPO date
- Price range
- Shares offered
- Valuation
- Revenue
- Net income
- Debt
- Risk factors
- Use of proceeds
- Underwriters
- SEC filing links

## Initial Sources

- SEC EDGAR company filings
- NASDAQ IPO calendar
- NYSE IPO listings
- Company S-1 filings
- Financial news sources

## Product Rule

If verified IPO data is unavailable, MarketMind AI must show:
“Not enough verified data”
instead of giving an Apply/Avoid recommendation.
